CONFIG/FILESYSTEMS.PHP
──────────────────────

    'admin' => [
        'driver' => 'local',
        'root' => public_path('images'),
        'url' => env('APP_URL').'/images',
        'visibility' => 'public',
        'throw' => false,
    ],


APP/MODELS/MOVIE.PHP
────────────────────

    protected $fillable = [
        ...
        'poster_image',
        ...
    ];

    public function getPosterImageUrl(): ?string
    {
        if ($this->poster_image) {
            return '/images/movies/' . $this->poster_image;
        }
        return null;
    }


APP/ADMIN/CONTROLLERS/MOVIECONTROLLER.PHP
──────────────────────────────────────────

    // En el formulario:
    $form->image('poster_image', __('admin.poster_image'))
        ->disk('admin')
        ->directory('movies')
        ->rules('nullable|image|mimes:jpeg,png,jpg,gif,webp|max:5120')
        ->help(__('admin.poster_image_help'));

    // Grid (listado):
    $grid->column('poster_image', __('admin.poster_image'))
        ->image('/images/movies/', 80, 120)->sortable();

    // Detail (detalle):
    $show->field('poster_image', __('admin.poster_image'))
        ->image('/images/movies/', 300, 450);

    // Eliminación:
    private function handleImageDelete(Movie $movie)
    {
        if ($movie->poster_image) {
            Storage::disk('admin')->delete('movies/' . $movie->poster_image);
        }
    }

ADMINISTRADOR:
──────────────

1. Panel Admin → Películas
2. Crear Nueva o Editar película
3. Campo "Imagen del Póster" → selecciona archivo
4. Guardar
5. ¡La imagen se almacena en /public/images/movies/


DESARROLLADOR FRONTEND:
───────────────────────

JavaScript:
  const movie = await fetch('/api/movies/1').then(r => r.json());
  const imageUrl = movie.poster_image_url; // /images/movies/1702360000_abc123.jpg

HTML:
  <img src="/images/movies/1702360000_abc123.jpg" alt="Póster">

Vue:
  <img :src="movie.poster_image_url" :alt="movie.title">

React:
  <img src={movie.poster_image_url} alt={movie.title} />

Solución: Verificar que existe en /public/images/movies/
