🔧 FRONTEND IMPLEMENTATION - NEXT STEPS

Step 1: Install Dependencies
────────────────────────────
$ cd cinea-frontend
$ npm install qrcode
$ npm install html2pdf (optional)

Step 2: Create Composable
────────────────────────────
📁 src/composables/useTicketValidator.js

Functions needed:
• validateTicket(id)      → calls GET /api/tickets/{id}/validate
• loadTicketDetails(id)   → calls GET /api/tickets/{id}/details
• loadQRCodes(id)         → calls GET /api/tickets/{id}/qr
• loadThermalFormat(id)   → calls GET /api/tickets/{id}/print-thermal
• printTicket(id)         → uses window.print()

Step 3: Create Components
────────────────────────────
📁 src/components/TicketDetailsCard.vue
   Shows: Movie, Cinema, Room, Date, Time, Seats, Total

📁 src/components/QRDisplayCard.vue
   Shows: QR codes for each seat with copy button

Step 4: Update PaymentSuccess.vue
────────────────────────────────
✅ Import useTicketValidator
✅ Import TicketDetailsCard
✅ Import QRDisplayCard
✅ onMounted:
   - Get ticketId from route.query.id
   - Validate ticket (endpoint #1)
   - If invalid → redirect to /checkout
   - If valid → load details (endpoint #3)
✅ Render TicketDetailsCard
✅ "View QR" button → load endpoint #2 → show modal
✅ "Print" button → load endpoint #4 → window.print()
✅ Show next steps section

Step 5: Add Print Styles
────────────────────────────
@media print {
  .no-print { display: none; }
  .container { width: 80mm; }
  /* Optimize for thermal printer */
}

Step 6: Test Everything
────────────────────────────
$ npm run dev

Test URL: http://localhost:5173/payment-success?id=123

Expected:
• Page loads with ticket info
• QR modal shows QR codes
• Print button opens print dialog
• Everything responsive on mobile
